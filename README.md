# nai harness

MaiBot 的 NAI 绘图插件，提供 `/nai`、`/uc`、提示词解析、角色检索、引用反推和重画。纯 tag 默认直出，中文与混合输入交给解析模型处理。画师串、画风和预设统一管理，出图成功默认只回复图片。

## 安装

1. 将插件文件夹放入目标 MaiBot 实例的 `plugins/` 目录，`_manifest.json` 与 `plugin.py` 应直接位于插件文件夹根目录。
2. 使用该 MaiBot 实例的 Python 安装依赖。Windows PowerShell 示例：`& "你的麦麦Python完整路径\python.exe" -m pip install -r "插件完整路径\requirements.txt"`。
3. 加载插件，在 MaiBot WebUI 的插件配置中打开 **nai harness**。首次加载生成实际使用的 `config.toml`；插件总开关默认关闭，接口列表默认留空。
4. 按下方步骤填写并保存，完成后重载插件。重载会取消正在处理的任务，请等当前任务结束再操作。更新前备份实际配置和插件数据目录。

## 首次配置

1. **开始使用**：填写全局管理员 QQ，确认是否允许群聊和私聊，选择默认绘图模型、图片尺寸。默认模型为 `nai-diffusion-5-full`，尺寸为 `832x1216`；上游只支持 4.5 时改为 `nai-diffusion-4-5-full`。
2. **绘图接口 → 普通模式**：添加一个服务，填写名称、完整接口 URL、接口格式，再添加一把具名 key 并填写 API 密钥。服务和 key 都保持启用；直接填密钥时，将“密钥环境变量”留空。会话关闭 NSFW 时使用这组接口。
3. **提示词与联网**：需要中文、混合词或自然语言输入时，保留解析开关，添加普通模式的文字解析服务，填写完整 URL、`openai_chat` 格式、文字模型名称和 key。需要角色联网查找时再配置搜索服务；仅使用纯 tag 可暂时跳过这一步。tag 查询默认启用，外置词库默认关闭。
4. 回到 **开始使用**，开启插件，保存并重载。先发送 `/nai 1girl, sitting, outdoors` 检查绘图接口；再用 `/nai 一个坐在窗边的女孩，水彩画风` 检查解析接口。
5. 需要 NSFW 时，分别填写绘图、解析和反推所需的 NSFW 服务，再在目标会话执行 `/nai nsfw on`。两组接口默认独立，开启 NSFW 后缺少对应服务会提示未配置。群聊由配置的管理员修改，私聊默认允许用户修改自己的设置。

| 服务用途 | 接口格式 | 应填写的地址与模型 |
| --- | --- | --- |
| 生成图片 | `native` / `openai_image` | 上游的 NAI 原生绘图或 OpenAI 兼容图片接口；使用默认/会话绘图模型 |
| 理解中文和混合提示词 | `openai_chat` | 支持插件解析与工具协议的文字模型接口；填写其文字模型名称 |
| 联网搜索 | `deepseek_search` / `tavily` / `searxng` | 对应协议的搜索服务地址与 key |
| 看图反推 | `openai_chat` / `json_tagger` | 视觉模型接口及模型名，或符合插件协议的图片标注服务 |

所有 URL 均需包含完整接口路径，例如服务要求的 `/v1/chat/completions`。绘图、解析、搜索和反推分别填写 key；示例地址与环境变量名请替换为自己的配置。填写环境变量名后，该 key 仅从指定变量读取，变量缺失时跳过。具体协议见 [配置说明](docs/CONFIGURATION.md)。

## 常用指令

| 指令 | 用途 |
| --- | --- |
| `/nai 内容` | 绘图；例如 `/nai 1girl, sitting /uc bad hands`，此处 `/uc` 只作用于本次请求 |
| `/uc 负面词`、`/uc`、`/uc 清空` | 保存、查看、清除自己的负面词；UC 和个人画风按用户保存 |
| `/nai 模型`、`/nai 模型 nai-diffusion-4-5-full` | 查看或修改当前会话模型；修改值必须在允许列表内 |
| `/nai nsfw`、`/nai nsfw on`、`/nai nsfw off` | 查看或修改当前会话模式；开启后，该会话的绘图、解析和反推使用 NSFW 接口 |
| `/nai 画风 模板名或画师串`、`/nai 画风 清空` | 保存或清除个人画风；模板在配置中定义，默认不向纯 tag 追加画风 |
| `/nai 反推` | 引用一条图片消息后发送，返回识别的 tag；需开启反推模块并配置对应模式的反推接口 |
| `/nai 重画`、`/nai 重画 新提示词 --seed=123` | 引用本插件生成的图片重画；默认仅限本人、本会话、未过期的生成记录 |
| `/nai 状态`、`/nai 取消`、`/nai 帮助` | 查看状态、取消自己当前会话的任务、查看指令帮助；已提交上游的请求可能继续执行并计费 |

直接发送 `/nai 重画` 默认使用自己在本会话最近一张作品的记录。其他来源的图片可先反推，再用得到的 tag 绘图。反推优先读取引用图，读取失败时提示错误。角色有歧义时按回执发送 `/nai 编号` 选择，候选默认 300 秒过期；明确查不到角色时提示并停止生成。自然对话绘图入口默认关闭，开启后需要用户发送确认指令。

## 高级设置

前三页完成基础连接；后三页分别为 **高级：反推与画风**、**高级：权限与用量**、**高级：维护与调优**。生成步数、默认负面词、解析轮次、超时、正文抓取、日志和网络选项可按需调整；功能开关、回复内容和重画继承规则在反推与画风页。本地词库使用外置 SQLite 文件，需自行准备并在高级维护页填写路径。

群管理 QQ 可通过 `permissions.group_managers` 按群设置，例如 `group_managers = { "群号" = ["管理员QQ"] }`；私聊使用由 `private_enabled` 控制，私聊修改模型/NSFW 由 `private_manage` 控制。全局和按群管理员仍受使用名单限制。允许名单留空表示不限制；本地额度按用户、群和模型计数，与上游账户余额分别管理。

服务顺序与服务内 key 顺序分别设置：`ordered` 从第一项开始，`round_robin` 每次轮换起点；服务与 key 可继续添加。标记 `paid = true` 的服务还需所在池 `allow_paid = true`。认证失败默认停用该 key，额度不足默认冷却 300 秒；修正凭据后，全局管理员可用 `/nai 恢复key 服务名 key名` 恢复。每 key 的失败规则、补购、模型映射、群配置和画风模板等复杂项在原文配置中填写，普通表单编辑会保留未展示的高级值。自动补购默认关闭。

表单分类见 [WebUI 配置](docs/CONFIG_WEBUI.md)，行为与覆盖顺序见 [配置说明](docs/CONFIGURATION.md)，全部字段见 [字段索引](docs/CONFIG_FIELDS.md)。高级设置的完整写法集中在 [配置参考](docs/config.reference.toml)，选取所需字段填入宿主实际使用的 `config.toml`。

## 常见问题

- **指令无反应或服务未配置**：确认加载的是目标实例中的插件，总开关已开启，保存后已重载；检查当前 NSFW 模式对应的服务池、服务/key 启用状态、环境变量和权限名单。
- **纯 tag 能画，中文不能画**：检查当前会话模式对应的解析服务 URL、文字模型和 key；涉及角色查找时，再检查搜索与 tag 查询服务。
- **只返回请求参数、不出图**：在高级维护页关闭“只解析，不生成图片”。该模式仅跳过绘图调用，解析、搜索和反推仍可能联网并计费。
- **备用服务没调用、认证失败或额度不足**：检查接口格式、模型允许范围、付费开关、key 冷却/停用状态，以及总尝试次数和超时预算。上游超时后重试可能再次扣费，先查服务方记录。
- **排队或超时**：用 `/nai 状态` 检查任务，必要时用 `/nai 取消`。默认同会话一次一个任务；并发数、等待队列和任务时限可在高级权限页调整。
- **反推或重画失败**：检查引用图片是否可读取、重画记录是否过期。建立重画引用记录需要宿主返回图片发送消息 ID；缺少该 ID 时，可直接发送 `/nai 重画` 使用自己的最近记录。
