# nai harness 中文分类配置

在 MaiBot WebUI 中打开插件配置。首次使用从前三页填写，后三页为高级设置；保存后重载插件生效。

| 标签页 | 内容 |
| --- | --- |
| 开始使用 | 总开关、管理员 QQ、群聊开关、私聊开关、默认模型和尺寸 |
| 绘图接口 | 生成图片的普通与 NSFW 服务、URL、密钥、调用顺序 |
| 提示词与联网 | 文字解析模型、搜索服务、tag 查询 |
| 高级：反推与画风 | 功能开关、反推服务、画风、重画规则和回复样式 |
| 高级：权限与用量 | 私聊管理权限、默认 NSFW 模式、用户与群名单、额度和排队 |
| 高级：维护与调优 | 生成参数、解析测试、调用限制、词库、正文抓取、日志和网络 |

## 添加服务

每个服务填写一个完整 URL，可继续添加多把密钥。服务和密钥的名称须在各自列表内唯一。`ordered` 按列表顺序调用，`round_robin` 每次轮换起点。

普通模式对应 `sfw`，NSFW 模式对应 `nsfw`，由会话的 NSFW 设置选择。绘图、文字解析和反推各有独立服务配置；每类服务的接口格式下拉框显示适用协议。

首次填写步骤见 [README](../README.md)，服务选择和覆盖顺序见 [配置说明](CONFIGURATION.md)。

## 原文配置

以下复杂项通过原文配置填写，完整写法见 [配置参考](config.reference.toml)：

- 按群管理员、群初始设置和并发覆盖。
- 模型降级映射、上游模型别名、请求头和额外请求参数。
- 服务默认失败策略、每把 key 的独立失败规则、超时覆盖和补购。
- 人工角色别名、画风模板、tag API 请求头。
- 特殊用户或群额度、按模型计数值。

在表单中修改 URL 或 key 时，已填写的高级项会保留。旧版 WebUI 的嵌套密钥输入框可能显示明文，分享配置页截图前请遮盖密钥。
